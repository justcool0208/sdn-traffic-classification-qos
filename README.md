# Software Defned Network Trafc Classifcation for QoS Optimization Using Machine Learning
## IT-258 Course Project 
(Status : _Feb 2025     Ongoing_)


This project focuses on classifying network traffic in a **Software Defined Networking (SDN)** environment using **Machine Learning** techniques to optimize **Quality of Service (QoS)**. By intelligently identifying traffic types, the SDN controller can make informed decisions for bandwidth allocation, prioritization, and congestion management.
